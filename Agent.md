# Agent Task Requirements & Progress Log

## Objective
Build complete HTML presentation decks (`presentation/index.html` for Vietnamese and `presentation/index.ja.html` for Japanese) based on `presentation.md` and `presentation.ja.md`. After completing each slide in the deck, commit the changes to git to ensure no data loss.

## Requirements & Design Directives
- **Resolution**: 16:9 aspect ratio responsive slide viewport.
- **Theme**: Clean, modern Japanese SaaS styling (`#06C755` LINE Green, `#0F172A` Dark, `#F8FAFC` Light).
- **Navigation**: Keyboard shortcuts (Left/Right/Space/PageUp/PageDown, Home/End, F for Fullscreen, P for Presenter Window), click buttons, touch swipe, and progress bar.
- **Presenter Notes**: Each slide contains `.speaker-notes-data` which updates the drawer and separate popup presenter window (`P`).
