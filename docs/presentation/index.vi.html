Slide 07 — Kiến trúc công nghệ

Tech Architecture & Core Stack

Sử dụng các công nghệ hiện đại, độ tin cậy cao và tích hợp sâu với LINE

Tech Architecture

⚛️ Frontend Web UI

React + Vite: Tải trang cực nhanh, phản hồi mượt mà, tối ưu hiển thị trên mọi thiết bị di động và máy tính.

🛡️ Backend API

Express + TypeScript: Thiết kế RESTful API chặt chẽ, kiểm soát kiểu dữ liệu mạnh mẽ và bảo mật phân quyền Đa người thuê (Multi-tenant).

🗄️ Database

PostgreSQL: Đảm bảo tính toàn vẹn dữ liệu ACID, quản lý mượt mà hàng triệu giao dịch từ nhiều chi nhánh.

🟢 LINE Ecosystem

LIFF + LINE Login + Messaging API: Khởi chạy ứng dụng không cần tải thêm app, đăng nhập 1-click & nhận thông báo push tự động.

Kiến trúc hệ thống sử dụng các công nghệ hiện đại.

Frontend được xây dựng với React và Vite cho tốc độ nhanh. Backend Express + TypeScript đảm bảo an toàn kiểu dữ liệu.

Database PostgreSQL bảo vệ tính ACID giao dịch. Tích hợp sâu bộ 3 công nghệ LINE: LIFF, LINE Login và Messaging API.

Slide 18 — Branch Stock

Stock thuộc về từng chi nhánh

Quản lý vòng đời tồn kho từ Reserve ➔ Release ➔ Consume

Stock Control
  • Hỗ trợ 2 chế độ kho: Tồn kho hữu hạn (Finite) & Không giới hạn (Unlimited)
  • Reserve (Giữ kho): Tự động khóa số lượng ngay khi khách Booking
  • Release (Khôi phục): Tự động hoàn trả kho khi Ticket bị Hủy/Vắng mặt
  • Consume (Khấu trừ): Trừ tồn kho thực tế khi Staff hoàn tất phục vụ
  • Ngăn chặn triệt để tình trạng bán vượt quá số lượng (Overselling)
